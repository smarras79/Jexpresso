# Elasticity

Elastic deformation as first-order hyperbolic conservation laws, which is the
form that fits a SEM/DG solver. Two 2D cases on their own gmsh grids, plus the
1D Timoshenko beam the set started from.

```bash
julia --project=. src/Jexpresso.jl Elasticity plane_wave2d    # verification
julia --project=. src/Jexpresso.jl Elasticity cantilever2d    # a bending beam
julia --project=. src/Jexpresso.jl Elasticity timoshenko1d    # reduced model
```

| case | dim | eqs | grid | boundaries |
|---|---|---|---|---|
| `plane_wave2d` | 2D | 5 | `square_periodic_16x16.msh` | none (doubly periodic) |
| `cantilever2d` | 2D | 7 | `beam_40x4.msh` | clamped + traction-free |
| `timoshenko1d` | 1D | 4 | built-in | simply supported |

Both grids are structured quad meshes generated by `make_meshes.py`
(`pip install gmsh && python3 problems/Elasticity/make_meshes.py`). One gmsh
quad becomes one spectral element carrying (nop+1)² LGL nodes.

## The 2D system: velocity–stress elastodynamics

State, plane strain, per unit volume:

```
U = (ρu, ρv, σxx, σyy, σxy)ᵀ
```

Balance of linear momentum plus the rate form of Hooke's law:

```
∂ₜ(ρu)  = ∂ₓσxx + ∂_y σxy
∂ₜ(ρv)  = ∂ₓσxy + ∂_y σyy
∂ₜσxx   = (λ+2μ) ∂ₓu + λ ∂_y v
∂ₜσyy   = λ ∂ₓu + (λ+2μ) ∂_y v
∂ₜσxy   = μ (∂_y u + ∂ₓv)
```

i.e. `∂ₜU + ∂ₓF(U) + ∂_y G(U) = 0` with

```
F(U) = -(σxx, σxy, (λ+2μ)u, λu,      μv)ᵀ
G(U) = -(σxy, σyy, λv,      (λ+2μ)v, μu)ᵀ
```

**The source is empty.** Every term is a divergence. That is the structural
difference from Timoshenko, whose shear coupling `κₛGAγ` and whose `-ω` are
undifferentiated and therefore have to sit in `S`.

### Characteristics

The flux Jacobian in any direction **n** has eigenvalues

```
±cp = ±√((λ+2μ)/ρ)     pressure (P) wave
±cs = ±√(μ/ρ)          shear (S) wave
 0                     the stress combination carrying no motion along n
```

so the system is hyperbolic, and symmetrizable by the mechanical energy

```
½ρ(u² + v²) + ½ σ : C⁻¹ : σ
```

which is the convex entropy; its flux is `-σ·v`, the mechanical power. Standard
upwind or Rusanov fluxes apply directly — these cases run on Jexpresso's
continuous SEM, so no Riemann solver is used, but the structure is there for a
DG variant.

Two incoming characteristics per boundary, so each boundary takes exactly two
conditions: a clamp supplies the two velocity components, a free surface
supplies the two components of the traction `σ·n`.

### Material

All three cases use the same non-dimensional material, defined once per case in
`elastic_properties()` / `timoshenko_properties()` in `user_flux.jl`:

| | |
|---|---|
| ρ = 1, E = 1, ν = 0.3 | → λ = 0.576923, μ = 0.384615 |
| cp = 1.160239 | P wave |
| cs = 0.620174 | S wave, cp/cs = 1.8708 |

In **plane strain** the bending modulus is `E/(1-ν²) = 1.0989`, not `E` — a
plane-strain beam is stiffer than the 1D beam model by that factor, which is
why `cantilever2d` and `timoshenko1d` do not report the same Ω₁.

## `plane_wave2d` — the verification case

An oblique plane P-wave on a doubly periodic unit square. With
**k** = (2π p/L, 2π q/L), **n** = **k**/|k| and φ = **k**·**x** − ωt, ω = cp|k|:

```
displacement   A n sin(φ)
velocity       -A ω n cos(φ)
stress         σij = A|k| (λ δij + 2μ ni nj) cos(φ)
```

Integer p, q make **k**·**x** periodic in both directions, so the wave simply
re-enters. `p = q = 1` puts it on the diagonal, which is what makes this a real
2D test rather than a 1D solution embedded in a 2D mesh: all five components are
active and both flux directions carry the wave.

**There are no boundaries at all.** What is being checked is the flux operator,
the metric terms and the periodic node matching, against an exact solution, with
the boundary treatment taken entirely out of the picture.

**The check:** the wave is exactly time-periodic with T = 2π/(cp|k|) = 0.6094494.
`:diagnostics_at_times` lands on whole multiples of T, so **every output frame
must reproduce the t = 0 frame**. Ten periods in, whatever has drifted is
dispersion and time-integration error and nothing else.

## `cantilever2d` — a bending beam, with no beam theory in it

Beam of length 1 and depth 0.1 (L/h = 10, the same beam `timoshenko1d` uses),
clamped on the x = 0 face, traction-free on the other three. Struck at t = 0
with a transverse velocity in the shape of the first bending mode, stress-free
and undeformed, and then left alone.

Seven equations: the five above plus **displacement recovery**,

```
U₆ = uₓ     ∂ₜuₓ + ∂ₓ(0) + ∂_y(0) = u
U₇ = u_y    ∂ₜu_y + ∂ₓ(0) + ∂_y(0) = v
```

Zero flux, so they add two zero eigenvalues and change neither the
characteristic structure nor the stable time step. They are reconstructions, not
conservation laws — but they are what turns the output into a picture of a beam
bending. **Warp the mesh by (uₓ, u_y) in ParaView.** They are also the only
source in this system.

Boundary conditions:

| face | imposed | free |
|---|---|---|
| `clamped`, x = 0 | u = 0, v = 0 (and uₓ, u_y pinned) | σxx, σyy, σxy |
| `free`, n = (±1,0) | σxx = 0, σxy = 0 | u, v, uₓ, u_y |
| `free`, n = (0,±1) | σyy = 0, σxy = 0 | u, v, uₓ, u_y |

**Why struck and not released from a static deflection.** Every boundary
condition is satisfied exactly by the initial state: σ ≡ 0 makes the three free
surfaces traction-free, and Φ₁(0) = Φ₁′(0) = 0 makes the clamp motionless.
Releasing a statically loaded beam instead means switching off a tip traction at
t = 0 — a step in time at that face, which launches a front a non-dissipative
scheme has no way to absorb.

Φ₁ is a mode of the *reduced 1D model*, not of the 2D elastic beam, so the
motion carries a little of the neighbouring modes too. That is not error — it is
the difference between the two models, and it is the reason to run this in 2D.

`:tend` is half an Euler–Bernoulli period (T ≈ 59.05, so `:tend` ≈ 29.53): the
beam swings from flat-and-moving, through maximum deflection at T/4, back to
flat-and-moving the other way. A slender beam's bending period is four orders of
magnitude longer than its elastic transit time, which is why even half a swing
is ~30 000 steps. That ratio is physics, not a deck choice.

## `timoshenko1d` — the reduced model

The shear-deformable beam as a 1D first-order hyperbolic system:

```
U = (ρA v, ρI ω, γ, χ)ᵀ

v = ẇ,  ω = φ̇,  γ = w_x - φ,  χ = φ_x

F(U) = -(κₛGA γ, EI χ, v, ω)ᵀ        S = (q, κₛGA γ, -ω, 0)ᵀ
```

Rows 1–2 are balance of linear and angular momentum, with fluxes minus the shear
force `Q = κₛGA γ` and the bending moment `M = EI χ`; rows 3–4 are the
compatibility conditions `γ̇ = v_x - ω` and `χ̇ = ω_x`. `κₛGA γ` and `-ω` sit in
the source because they are **undifferentiated**, not because they are
nonlinear: the system is linear with constant Jacobian, whose spectrum splits
into two decoupled pairs at ±√(κₛG/ρ) and ±√(E/ρ), symmetrizable by
½(ρA v² + ρI ω² + κₛGA γ² + EI χ²).

Euler–Bernoulli has no such form: its fourth-order operator makes it dispersive,
not hyperbolic, and the best two-field form has second-order fluxes wanting an
LDG-type treatment rather than a Riemann solver. It is recovered here as the
stiff relaxation limit κₛGA → ∞ (γ → 0).

The case is the first flexural standing mode of a simply supported beam,
released from rest. Ω is the lower (flexural) root of the Timoshenko frequency
equation

```
(ρIρA/κₛGA) Ω⁴ - [ρI k² + EI ρA k²/κₛGA + ρA] Ω² + EI k⁴ = 0
```

giving Ω = 0.28023 against the Euler–Bernoulli 0.28491 — the 1.6% shear
flexibility costs at L/h = 10 — and a period T = 22.4215, which is exactly
`:tend`. `user_analytic.jl` supplies the exact solution, so the shared 1D
plotter overlays it on **every** output frame: the gap between the two curves is
entirely the discretisation's, and after one full period every field must land
back on its initial profile.

**Large deformation.** The geometrically exact (Simo–Reissner) beam keeps the
same shape — `∂ₜ(ρA 𝐯) - ∂ₓ𝐧 = 𝐧̄`, `∂ₜ(𝐈ω) - ∂ₓ𝐦 = 𝐱,ₓ × 𝐧 + 𝐦̄` — but
`𝐧, 𝐦` become nonlinear functions of the strain measures through the rotation
field, and the angular momentum source picks up the `𝐱,ₓ × 𝐧` term.

## A bug this equation set flushed out

Building the 1D cases turned up a real defect in the 1D SEM kernels, fixed in
the same branch. The 1D volume term weighted the flux by `ω[i]` and the source
by `ω[i]`, and the assembled result is divided by the lumped mass matrix
`M[i] = Je[i]·ω[i]`:

```
flux:    ω·dFdξ  / (Je·ω)  =  dFdξ/Je = dF/dx    correct
source:  ω·S     / (Je·ω)  =  S/Je               wrong by 2/Δx
```

The flux is right *by cancellation*: in 1D `dF/dx = dFdξ·dξdx` with
`dξdx = 1/Je`, so weighting by `ω·Je` would immediately undo itself and the
kernel simply never wrote `Je` at all. The source has no `dξdx` to cancel
against, so the same (absent) weighting left it scaled by `1/Je`. **The 2D and
3D kernels form `dF/dx` explicitly and then weight by `ω·Jac`, so only 1D was
affected** — in all of its paths at once: `_expansion_inviscid!` and
`_expansion_inviscid_laguerre!` on the CPU, and `_build_rhs_gpu_v0!` on the GPU.

Nothing caught it because only four 1D cases have a live source and all four are
*sponges*, whose coefficient is a free tuning knob that absorbed the factor. The
one 1D case with a genuinely physical source, `CompEuler/nozzleanderson`, is not
in CI. `CompEuler/wave1d_lag` *is*, and its `Je = 0.05` is the same in the CG and
the Laguerre region, so the compensating `1/0.05` is folded into that deck and
its solution is unchanged to round-off.

The 2D cases here are unaffected either way: `plane_wave2d` has no source at
all, and `cantilever2d`'s displacement recovery goes through the 2D path, which
was always correct.
